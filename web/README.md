# web/

前端页面（原生 HTML/CSS/JS，无构建步骤，P2 已实现）。

## 功能

- 工作流选择（W1 概念原画 / W2 深度图）
- 动态参数表单（prompt、seed、尺寸、步数、CFG 等）
- 图片上传 或 选择服务器已有图片（输入目录 / 历史输出目录，可刷新）
- 任务列表 + 状态轮询（2 秒一次）
- 结果预览与下载

## 说明

页面由后端 `server/app/main.py` 直接托管（`/` 与 `/static/*`），
无需单独部署。后续如需更丰富的交互，可迁移到 Vue/React + Vite，
接口不变。

## 3D / 2D 场景页

- `scene.html?batch=…`：3D 场景（真实几何酒吧 + 2D 序列帧角色贴图）
- `scene2d.html?batch=…`：扁平 2D 横版场景 + 3D 角色模型
  - 场景：概念图平面背景 + 剪影道具 + 纯色地面，不做 3D 透视
  - 角色：W7（TripoSR）把 2D 角色图转成真正的 3D 模型（GLB）后放入场景；
    尚未生成时用内置低模酒保演示，同样支持旋转查看立体
  - 操作：A/D 或 ←/→ 移动 · 空格旋转角色 · P 恢复自动演出
  - WebGL 不可用时自动降级为纯 Canvas 2D 模式
